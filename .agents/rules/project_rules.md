# Project Rules

## Правило 1: Версия Godot (Godot 4.3+, таргет 4.7)
- Проект разрабатывается строго под Godot версии 4.3+ (с прицелом на 4.7).
- Использовать только синтаксис и методы Godot 4.
- Запрещён синтаксис Godot 3 (никаких export, onready без собачки @, старых методов connect(), yield, старых твинов и т.д.).
- Всегда использовать современные возможности GDScript 2.0:
  - @export, @onready
  - Строгая типизация: Array[Type], Dictionary
  - Встроенные типы Godot 4 (Vector3, Vector2i, create_tween(), signal.connect(), signal.emit())
- Формат имени файлов PascalCase.

## Правило 2: Сохранение кодировки UTF-8 (Никакого PowerShell для файлов с кириллицей)
- Все комментарии, UI-тексты и логи в проекте пишутся на русском языке.
- Запрещено использовать PowerShell для записи, чтения или правки файлов проекта (.gd, .tscn, .tres, .md), так как Windows PowerShell портит кодировку UTF-8 (ломает кириллицу вопросительными знаками).
- Для редактирования и создания файлов использовать только встроенные инструменты агента (write_file, edit_file) или Python-скрипты с явным указанием encoding='utf-8'.

## Правило 3: Запрет на автоматические коммиты в Git (Без спроса не коммитить)
- Никогда не выполнять git commit автоматически или без прямого запроса пользователя.
- Все правки кода должны оставаться в рабочей директории (working directory / unstaged), чтобы пользователь мог сам проверить diff и решить, когда и с каким сообщением делать коммит.

## Правило 4: Путь к исполняемому файлу Godot 4.7
- Путь к консольной версии движка Godot 4.7 для запуска, проверки скриптов и тестов: `c:/Program Files/Godot/Godot_47/Godot_v4.7.2-stable_win64_console.exe`.
